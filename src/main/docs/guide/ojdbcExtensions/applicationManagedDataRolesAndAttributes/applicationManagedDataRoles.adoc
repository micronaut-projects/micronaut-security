If one or more roles in api:security.authentication.Authentication[] begin with a specified prefix, then the provider will
recognize them as application-managed `DATA ROLE` names that should be enabled for the end user.
The prefix is specified by the parameter:

`datasources.*.data-source-properties.oracle.jdbc.provider.endUserSecurityContext.rolePrefix`

The default value for this parameter is `ORACLE_DATA_ROLE_`.

The name of a `DATA ROLE` should appear after the specified prefix. For example, with the default prefix, if the authenticated user has a role with the value `ORACLE_DATA_ROLE_ADMIN`, the
provider recognizes a `DATA ROLE` named `ADMIN`.

In addition to the role prefix, the provider can also be configured with a fixed set of data role names using the parameter:

`datasources.*.data-source-properties.oracle.jdbc.provider.endUserSecurityContext.dataRoles`
