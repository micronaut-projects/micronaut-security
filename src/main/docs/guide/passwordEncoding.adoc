Applications that store passwords must store a salted, one-way hash of each password and never the password itself. Micronaut Security defines the api:security.password.PasswordEncoder[] API for this purpose:

[source,java]
----
public interface PasswordEncoder {

    String encode(String rawPassword);

    boolean matches(String rawPassword, String encodedPassword);
}
----

`encode` returns the value to store. It includes the salt and the parameters required to verify the password later. `matches` verifies a password against a stored value.

Every implementation honours the same contract:

* Encoding the same password twice produces different results, and the result never contains the password.
* Every character of the password is significant. Implementations do not truncate the password or alter its case or whitespace.
* `matches` returns `false`, instead of throwing an exception, for a stored value that the implementation cannot parse.
* Implementations are safe for use by multiple threads.

The API is in its own module and has no dependency on the rest of Micronaut Security:

dependency:micronaut-security-password[groupId=io.micronaut.security]

You do not normally add that dependency yourself. Instead, add an implementation, such as <<passwordEncodingArgon2, Argon2id>>, which contributes a api:security.password.PasswordEncoder[] bean.

== Usage

Encode a password when a user registers or changes their password:

snippet::io.micronaut.security.docs.passwordencoding.UserStore[tags="clazz"]

<1> Store the encoded password, never the raw password.

Verify the password in an <<authenticationProviders, authentication provider>>:

snippet::io.micronaut.security.docs.passwordencoding.PasswordAuthenticationProvider[tags="clazz"]

<1> Compare the supplied password with the stored value.

NOTE: The example responds faster for a user that does not exist than for a wrong password, which can reveal which usernames are registered. If that matters to your application, verify the supplied password against a fixed encoded password when the user is not found.
