The filter is enabled by default and applies to every request path. You can disable it or restrict it to a https://docs.micronaut.io/latest/api/io/micronaut/http/uri/UriMatchTemplate.html[URI pattern]:

[configuration]
----
micronaut:
  security:
    fetch-metadata:
      filter:
        enabled: true
        pattern: /api/**
----
