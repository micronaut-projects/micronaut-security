api:security.csp.ContentSecurityPolicyGenerator[] is the main policy-generation API. Its default implementation, api:security.csp.DefaultContentSecurityPolicyGenerator[], builds directives from the `micronaut.security.csp` configuration.

The request-aware `contentSecurityPolicy(HttpRequest)` method returns an api:security.csp.ContentSecurityPolicy[] containing the ordered directives for that response. It can therefore add request-specific values such as `script-src` and `style-src` nonces. The module serializes the policy with semicolons and writes it to the response. Returning `null` tells the module not to write a CSP header for that request.

To take complete control, provide a bean implementing api:security.csp.ContentSecurityPolicyGenerator[]; the default implementation is only loaded when no other generator bean exists:

[source,java]
----
import io.micronaut.http.HttpRequest;
import io.micronaut.security.csp.ContentSecurityPolicy;
import io.micronaut.security.csp.ContentSecurityPolicyDirective;
import io.micronaut.security.csp.ContentSecurityPolicyGenerator;
import jakarta.inject.Singleton;

import java.util.List;

@Singleton
class ApplicationContentSecurityPolicyGenerator implements ContentSecurityPolicyGenerator {
    @Override
    public ContentSecurityPolicy contentSecurityPolicy(HttpRequest<?> request) {
        return new ContentSecurityPolicy(List.of(
            new ContentSecurityPolicyDirective(DEFAULT_SRC, QUOTED_SELF),
            new ContentSecurityPolicyDirective(OBJECT_SRC, QUOTED_NONE)));
    }
}
----

To customize one part of the default policy, subclass api:security.csp.DefaultContentSecurityPolicyGenerator[] and override the corresponding protected directive method. The subclass must declare a constructor with the same parameters as the injected constructor of api:security.csp.DefaultContentSecurityPolicyGenerator[] and pass them to it, so that the `micronaut.security.csp` configuration keeps applying.

NOTE: A custom generator is also the escape hatch for directives or source expressions that the directive-specific configuration properties do not expose. Construct an api:security.csp.ContentSecurityPolicy[] from api:security.csp.ContentSecurityPolicyDirective[] values. Each directive accepts its name and already serialized value.
