api:security.csp.ContentSecurityPolicyGenerator[] is the main policy-generation API. Its default implementation, api:security.csp.DefaultContentSecurityPolicyGenerator[], builds directives from the `micronaut.security.csp` configuration.

The request-aware `contentSecurityPolicy(HttpRequest)` method returns an api:security.csp.ContentSecurityPolicy[] containing the ordered directives for that response. It can therefore add request-specific values such as `script-src` and `style-src` nonces. The module serializes the policy with `ContentSecurityPolicy.toHeaderValue()` and writes it to the response; `toString()` redacts nonces so that a logged policy does not leak them. Returning `null` tells the module not to write a CSP header for that request.

To take complete control, provide a bean implementing api:security.csp.ContentSecurityPolicyGenerator[]; the default implementation is only loaded when no other generator bean exists:

snippet::io.micronaut.security.docs.cspgenerator.ApplicationContentSecurityPolicyGenerator[tags="clazz"]

To customize one part of the default policy, subclass api:security.csp.DefaultContentSecurityPolicyGenerator[] and override the corresponding protected directive method. The subclass declares a constructor that takes api:security.csp.conf.ContentSecurityPolicyConfiguration[] and api:security.csp.conf.ContentSecurityPolicyDirectiveConfigurations[] and passes them to the constructor of api:security.csp.DefaultContentSecurityPolicyGenerator[], so that the `micronaut.security.csp` configuration keeps applying.

snippet::io.micronaut.security.docs.cspgenerator.ImagesContentSecurityPolicyGenerator[tags="clazz"]

The subclass can also override `nonce(HttpRequest)` to supply the nonce of nonce-capable directives from somewhere other than the `cspNonce` request attribute, and read its configuration through `getCspConfiguration()` and `getDirectiveConfigurations()`.

IMPORTANT: The generator, and a custom api:security.csp.nonce.ContentSecurityPolicyNonceGenerator[], run for every matching response, typically on the HTTP server's event loop. They must not block: load policies that depend on external data, such as per-tenant policies, ahead of time and cache them.

NOTE: A custom generator is also the escape hatch for directives or source expressions that the directive-specific configuration properties do not expose. Construct an api:security.csp.ContentSecurityPolicy[] from api:security.csp.ContentSecurityPolicyDirective[] values. Each directive accepts its name and already serialized value.
