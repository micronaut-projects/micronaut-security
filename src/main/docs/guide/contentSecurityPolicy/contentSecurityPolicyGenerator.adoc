api:security.csp.ContentSecurityPolicyGenerator[] is the main policy-generation API. Its default implementation, api:security.csp.DefaultContentSecurityPolicyGenerator[], builds directives from the `micronaut.security.csp` configuration.

The request-aware `contentSecurityPolicy(HttpRequest)` method returns an api:security.csp.ContentSecurityPolicy[] containing the ordered directives for that response. It can therefore add request-specific values such as `script-src` and `style-src` nonces. The server filter serializes the policy with semicolons. Returning `null` tells the filter not to write a CSP header for that request.

To customize one part of the default policy, subclass api:security.csp.DefaultContentSecurityPolicyGenerator[] and override the corresponding protected directive method. To take complete control, provide a bean implementing api:security.csp.ContentSecurityPolicyGenerator[]; the default implementation is only loaded when no other generator bean exists.

NOTE: A custom generator is also the escape hatch for directives or source expressions that the directive-specific configuration properties do not expose. Construct an api:security.csp.ContentSecurityPolicy[] from api:security.csp.ContentSecurityPolicyDirective[] values. Each directive accepts its name and already serialized value.
