The module is enabled by default and writes an enforcing `Content-Security-Policy` header on every HTTP response. It starts from a deny-by-default policy:

* `default-src 'none'`
* `base-uri 'none'`
* `connect-src 'none'`
* `font-src 'none'`
* `object-src 'none'`
* `frame-ancestors 'none'`
* `frame-src 'none'`
* `script-src 'none'`
* `img-src 'none'`
* `manifest-src 'none'`
* `media-src 'none'`
* `style-src 'none'`
* `worker-src 'none'`
* `form-action 'self'`
* `require-trusted-types-for 'script'`

It does not emit `prefetch-src`, `fenced-frame-src`, or `report-uri` unless you enable them explicitly. `prefetch-src` is disabled by default because Safari does not recognize the directive.

This baseline intentionally blocks most existing resource loading. Configure only the directives and source expressions required by your application.
