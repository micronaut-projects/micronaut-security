You can add host or URL source expressions to `script-src`, but URL allowlists are the least recommended approach for controlling script execution. An allowlisted origin may contain attacker-controlled JSONP endpoints, uploaded content, or vulnerable libraries. Never allowlist public, multi-tenant CDNs such as jsDelivr, unpkg or cdnjs: they serve arbitrary packages, so any attacker who can inject a script tag can load their own code from them. Prefer nonces or hashes whenever possible.

[configuration]
----
micronaut:
  security:
    csp:
      script-src:
        self: true
        values:
          - "'sha256-Eco45CPSfPGYCeRWuzpCqnc/toI8+r22Lkjfm5XoezE='"
          - https://static.example.com
----

NOTE: The TOML tab above escapes the single quotes as `\'`, which TOML does not accept. In TOML, write the value without backslashes, for example `values = ["'sha256-Eco45CPSfPGYCeRWuzpCqnc/toI8+r22Lkjfm5XoezE='"]`.

The configuration generates:

[source,text]
----
script-src 'self' 'sha256-Eco45CPSfPGYCeRWuzpCqnc/toI8+r22Lkjfm5XoezE=' https://static.example.com
----

URL and host source expressions are emitted without single quotes.
