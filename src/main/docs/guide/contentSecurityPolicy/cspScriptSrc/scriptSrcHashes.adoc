You can provide https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP#hashes[hash source expressions] as values of the `script-src` directive. The digest must match the script content exactly:

[configuration]
----
micronaut:
  security:
    csp:
      script-src:
        nonce: false
        self: true
        values:
          - 'sha256-Eco45CPSfPGYCeRWuzpCqnc/toI8+r22Lkjfm5XoezE='
----

The configuration generates:

[source,text]
----
script-src 'self' 'sha256-Eco45CPSfPGYCeRWuzpCqnc/toI8+r22Lkjfm5XoezE='
----

The module adds the required single quotes around configured hashes. This example disables nonce generation only to make the resulting hash-based policy deterministic; nonces and hashes may be used together.
