You can provide https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP#hashes[hashes] as one of the values of the `script-src` directive via configuration

[configuration]
----
micronaut:
  security:
    csp:
      script-src:
        self: true
        hashes:
          - sha256-Eco45CPSfPGYCeRWuzpCqnc/toI8+r22Lkjfm5XoezE=
----

The `script-src` value for the above configuration will be `'self' 'sha256-Eco45CPSfPGYCeRWuzpCqnc/toI8+r22Lkjfm5XoezE='`
