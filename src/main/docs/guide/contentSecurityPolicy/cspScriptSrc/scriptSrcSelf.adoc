You can add `'self'` to `script-src` to allow scripts from the protected document's origin:

[configuration]
----
micronaut:
  security:
    csp:
      script-src:
        self: true
----

Nonce generation remains enabled by default, so this adds `'self'` alongside the request-specific nonce. Treat `'self'` as a broader permission than a nonce or hash because it permits every script served from the application origin.
