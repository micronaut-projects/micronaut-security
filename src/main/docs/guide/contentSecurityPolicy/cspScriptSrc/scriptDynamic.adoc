You can enable https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/script-src#strict-dynamic[`'strict-dynamic'`] for the `script-src` directive. In supporting browsers, it propagates trust from a nonce- or hash-authorized script to scripts that it loads dynamically:

[configuration]
----
micronaut:
  security:
    csp:
      script-src:
        nonce: true
        strict-dynamic: true
----

The generated directive contains both the request nonce and `'strict-dynamic'`. CSP3 browsers then ignore `'self'`, host and scheme sources, so every `script` element must carry the nonce or match a hash; adding `strict-dynamic` to a policy that allows scripts with `self` blocks every script without a nonce. Without a nonce or hash, `'strict-dynamic'` blocks every script, and the module logs a warning at startup.
