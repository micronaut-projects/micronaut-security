When you add the `micronaut-security` dependency, it contributes a https://docs.micronaut.io/latest/guide/#filters[Micronaut HTTP Server Filter] - the api:security.filters.SecurityFilter[].

image::securityfilter.png[]

For each request, the filter evaluates the request against the beans of type api:security.filters.AuthenticationFetcher[]. Fetchers are consulted sequentially in their `Ordered` precedence, and the first one to emit an api:security.authentication.Authentication[] wins; fetchers of lower precedence are not invoked once an authentication has been resolved.

NOTE: A custom `AuthenticationFetcher` must return a publisher that either emits a single `Authentication` or completes empty. When using `Mono.create`, emit only one terminal signal.

Then, the optional authentication is evaluated against every bean of type api:security.rules.SecurityRule[] to determine if the request is authorized. If not authorized, an api:security.authentication.AuthorizationException[] is thrown.
