Micronaut Security provides the `micronaut-security-ojdbc-extensions` module for integration with https://github.com/oracle/ojdbc-extensions[Oracle JDBC Driver Extensions].
The module registers an https://docs.oracle.com/en/database/oracle/oracle-database/26/jajdb/oracle/jdbc/spi/EndUserSecurityContextProvider.html[Oracle JDBC `EndUserSecurityContextProvider`] that adapts the current Micronaut Security authentication to an Oracle JDBC https://docs.oracle.com/en/database/oracle/oracle-database/26/ddscg/end-user-security-context.html[End-User Security Context].

To use the module, add the following dependency:

dependency:micronaut-security-ojdbc-extensions[groupId=io.micronaut.security]

Additionally, you have to add an implementation of the HTTP Client, either https://docs.micronaut.io/latest/guide/#nettyHttpClient[Netty Based HTTP Client] or the https://docs.micronaut.io/latest/guide/#jdkHttpClient[JDK HTTP Client].

Configure your Oracle datasource to use the Micronaut Security OJDBC provider:

[configuration]
----
datasources:
  default:
    data-source-properties:
      "oracle.jdbc.provider.endUserSecurityContext": ojdbc-provider-micronaut-end-user-security-context
----

The provider obtains a database access token with the OAuth 2.0 Client Credentials flow and attaches the current Micronaut Security token as the end user token.
Configure the token endpoint and client credentials as datasource properties:

[configuration]
----
datasources:
  default:
    data-source-properties:
      "oracle.jdbc.provider.endUserSecurityContext": ojdbc-provider-micronaut-end-user-security-context
      "oracle.jdbc.provider.endUserSecurityContext.tokenUrl": https://auth.example.com/oauth2/token
      "oracle.jdbc.provider.endUserSecurityContext.clientId": database-client
      "oracle.jdbc.provider.endUserSecurityContext.clientSecret": ${OAUTH_CLIENT_SECRET}
      "oracle.jdbc.provider.endUserSecurityContext.scope": https://database.example/.default
----

NOTE: Store `clientSecret` outside source control, for example in an environment variable.

The following provider parameters are supported:

`tokenUrl`::
OAuth 2.0 token endpoint URL. This parameter is required.

`clientId`::
OAuth 2.0 client identifier. This parameter is required.

`clientSecret`::
OAuth 2.0 client secret. This parameter is required and is marked as a sensitive OJDBC provider parameter.

`scope`::
Optional OAuth 2.0 scope sent with the Client Credentials request.

`dataRoles`::
Optional comma-separated Oracle Database data roles to enable for the end user.

`authorityRolePrefix`::
Optional Micronaut Security role prefix used to derive Oracle Database data roles from the current authentication. The default prefix is `ORACLE_DATA_ROLE_`; for example, a Micronaut role named `ORACLE_DATA_ROLE_REPORTING` enables the Oracle Database data role `REPORTING`.

`endUserContextAttributes`::
Optional JSON object containing fixed Oracle Database END USER CONTEXT attributes. The object keys are END USER CONTEXT names, and each value must be a JSON object containing the attributes for that context.

`authorityAttributesPrefix`::
Optional Micronaut Security role prefix used to derive END USER CONTEXT attributes from the current authentication. The prefix is removed from each matching role and the remaining role value is parsed as an END USER CONTEXT attributes JSON object.

For example, the following configuration sets fixed data roles and fixed END USER CONTEXT attributes:

[configuration]
----
datasources:
  default:
    data-source-properties:
      "oracle.jdbc.provider.endUserSecurityContext": ojdbc-provider-micronaut-end-user-security-context
      "oracle.jdbc.provider.endUserSecurityContext.tokenUrl": https://auth.example.com/oauth2/token
      "oracle.jdbc.provider.endUserSecurityContext.clientId": database-client
      "oracle.jdbc.provider.endUserSecurityContext.clientSecret": ${OAUTH_CLIENT_SECRET}
      "oracle.jdbc.provider.endUserSecurityContext.dataRoles": REPORTING,HR_READ
      "oracle.jdbc.provider.endUserSecurityContext.endUserContextAttributes": '{"hr.employee":{"department":"Sales"},"app.audit":{"source":"micronaut"}}'
----

When there is no current Micronaut Security authentication, the provider returns `null` and does not create an Oracle JDBC end user security context.
