You can provide a bean of type api:security.reporting.ReportingEndpointProvider[] for dynamic registering reporting endpoints.

The filter combines provider results with endpoints declared in configuration. A provider can return `null` when it does not contribute an endpoint for a particular request. Endpoint group names must remain unique after all configured and provider-generated endpoints are combined. When two endpoints share a name, the filter keeps the first one and logs a warning for the other. Endpoints declared in configuration or as beans come before provider endpoints, so a provider cannot replace them.

An endpoint returned by a provider must also have a valid group name and a URL. The filter leaves out an endpoint that fails either check and logs a warning naming the provider, so the response is still served with the remaining endpoints.
