You can use ann:security.annotation.RunAsUser[] when you only need to specify the run-as user name and roles.

snippet::io.micronaut.security.docs.authentication.RunAsUserService[tags="clazz"]

Annotating a Micronaut bean class with ann:security.annotation.RunAsUser[] applies the run-as authentication to intercepted method invocations on that bean.
Micronaut Security maps ann:security.annotation.RunAsUser[] to ann:security.annotation.RunAsAuthentication[] at compilation time.

[source,java]
----
@RunAsUser("sergio")
----

The preceding example is equivalent to:

[source,java]
----
@RunAsAuthentication("""
    {"name":"sergio"}""")
----

You can also supply roles:

[source,java]
----
@RunAsUser(name = "sergio", roles = {"ROLE_USER", "ROLE_ADMIN"})
----

The preceding example is equivalent to:

[source,java]
----
@RunAsAuthentication("""
    {"name":"sergio","attributes":{"roles":["ROLE_USER","ROLE_ADMIN"]}}""")
----

Use ann:security.annotation.RunAsAuthentication[] directly when the run-as authentication needs custom attributes.
