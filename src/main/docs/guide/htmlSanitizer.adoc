Micronaut Security includes an optional HTML sanitizer module that adapts https://github.com/OWASP/java-html-sanitizer[OWASP Java HTML Sanitizer] to the Micronaut Core api:micronaut.http.util.HtmlSanitizer[] API.

Add the dependency to enable the OWASP-backed sanitizer:

dependency:micronaut-security-html-sanitizer[groupId=io.micronaut.security]

When this module is present, it contributes an api:micronaut.http.util.HtmlSanitizer[] bean backed by OWASP Java HTML Sanitizer. The bean replaces the Core entity-encoding fallback and is secondary to an application-provided api:micronaut.http.util.HtmlSanitizer[] bean.

By default, the module combines the OWASP block, formatting, and link policies. It does not allow scripts, event-handler attributes, `javascript:` URLs, CSS style handling, images, or tables by default.

include::{includedir}configurationProperties/io.micronaut.security.html.HtmlSanitizerConfigurationProperties.adoc[]

You can opt into additional OWASP policies with configuration:

[configuration]
----
micronaut:
  security:
    html-sanitizer:
      policies:
        - BLOCKS
        - FORMATTING
        - LINKS
        - IMAGES
----

To replace only the OWASP policy while keeping the Micronaut api:micronaut.http.util.HtmlSanitizer[] integration, provide a named `org.owasp.html.PolicyFactory` bean:

[source,java]
----
import io.micronaut.security.html.OwaspHtmlSanitizer;
import io.micronaut.context.annotation.Factory;
import jakarta.inject.Named;
import jakarta.inject.Singleton;
import org.owasp.html.PolicyFactory;
import org.owasp.html.Sanitizers;

@Factory
class HtmlSanitizerPolicyFactory {

    @Singleton
    @Named(OwaspHtmlSanitizer.POLICY_FACTORY)
    PolicyFactory sanitizerPolicy() {
        return Sanitizers.FORMATTING.and(Sanitizers.LINKS);
    }
}
----

To replace the module completely, provide your own api:micronaut.http.util.HtmlSanitizer[] bean. To disable the module without removing the dependency, set `micronaut.security.html-sanitizer.enabled=false`.

Only trust the sanitized output returned by api:micronaut.http.util.HtmlSanitizer[]. Keep contextual output encoding and template escaping enabled, and do not treat removed tags or attributes as proof that the original input was safe.
