When you set `micronaut.security.authentication=idtoken`, api:security.oauth2.endpoint.token.response.IdTokenLoginHandler[] a bean of type api:security.handlers.LoginHandler[] and api:security.token.jwt.cookie.JwtCookieClearerLogoutHandler[] a bean of type api:security.handlers.LogoutHandler[] are enabled. Additionally, a link:{api}/io/micronaut/security/token/jwt/nimbus/ReactiveJwksSignature.html[ReactiveJwksSignature] bean is registered for the `jwks_uri` of each OpenID provider, so ID tokens issued by the provider can be used as request credentials, and api:security.oauth2.client.IdTokenClaimsValidator[] verifies that they were issued to this client.
